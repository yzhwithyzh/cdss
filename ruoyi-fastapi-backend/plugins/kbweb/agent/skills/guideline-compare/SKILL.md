# 指南比较与定义

## 库内实际有的指南
用 `search_recommendations` 查。目前结构化入库的只有两部：
中国早期结直肠癌预防、诊断和治疗指南（2024）、新加坡结肠息肉内镜处理临床指导（2022）。
USMSTF 2020、ESGE 2020、BSG 2020 **不在库内**，只能引用 surveillance-interval 技能中的草稿表并标【待原文核对】。

## 比较类问题
- 用表格逐指南列出，不合并、不取平均。
- 先说"一样/不一样"，再列差异点。
- 对每个差异，尽量用 `search_literature` 找解释差异的研究（如重新分组后的风险比较），引用【source_id】。

## 定义类问题
- "进展期腺瘤""高危""低危"等在不同指南中定义不同，分别给出，并说明按哪个定义结论会变。
- 定义中涉及观察者一致性差的判读（如 <10 mm 腺瘤的绒毛成分），检索相关研究提示判读不确定性。

## 版本与时效
- 指南有新旧版本时说明以新版为准，旧版建议仅作对照。
- 术语随时间变化（增生性息肉 → 无蒂锯齿状病变；SSA/P → SSL）：检索时新旧术语都要用，回答中提示术语版本。
