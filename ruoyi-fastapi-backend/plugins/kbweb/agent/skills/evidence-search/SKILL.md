# 证据检索与综合

## 检索（至少两轮，最多四轮）
1. **第一轮（宽）**：把问题翻译成英文医学术语 + 同义词/缩写，调用 `search_literature`，每次 6–10 个检索词，只用英文。
   只围绕问题里出现的概念，不要添加无关主题（如问腺瘤随访时不要加 EMR、SSL）。
   例：分片EMR → piecemeal EMR, EPMR, endoscopic piecemeal mucosal resection；
   无蒂锯齿状病变 → sessile serrated lesion, SSL, sessile serrated adenoma, SSA/P。
2. **第二轮（窄）**：用第一轮结果标题里出现的更具体术语再检索；需要高等级证据时加 `design="系统评价"` 或 `design="随机对照"`。
3. 需要中文文献时，单独用中文检索词再查一轮（中英文混在一起会让英文文献排不上来）。
4. 问题涉及具体数字/亚组时，再用 `search_passages` 查原文段落，或 `search_findings` 查已结构化的效应值。
5. 用 `get_record` 打开最相关的 2–4 篇读摘要，确认它确实回答了问题后才能引用。只看标题不能下结论。

## 取舍
- 优先：系统评价/Meta 分析 > 随机对照 > 前瞻性队列 > 回顾性研究 > 病例系列。
- 证据之间有分歧时，**必须同时展示两边**，不能只报支持一方的。
- 研究与指南结论不一致时，分开说明，不要用证据改写指南建议。
- 动物/体外/机制研究只能作背景，不能作为临床结论的依据。

## 重复记录与同一研究
同一作者、相近标题、同一队列/试验名、会议摘要与全文、试验注册与正式发表 → 视为同一研究，只算一项，
并在回答中写明"【A】与【B】为同一研究的不同记录"。不要把它们当作相互印证的多项研究。

## 引用
- 每个事实或数字后紧跟【source_id】；只能引用本轮工具返回过的 source_id。
- 数字照抄原文（含置信区间、P 值），注明是 OR/HR/RR 等哪种指标。
- 库内找不到证据时直接说"库内未检索到直接证据"，不要用常识补出处。
