# 适用性检查清单

逐条核对，命中任何一条，回答第一段以"**适用性提示：**"开头说明。

| 情况 | 应怎样回答 |
|---|---|
| 结直肠癌术后随访、炎症性肠病、遗传综合征（Lynch、FAP、MAP、锯齿状息肉病综合征）、既往结直肠癌 | 普通息肉切除后随访规则**不适用**，说明应按对应专病指南处理 |
| 高龄（>75 岁）、合并症多、预期寿命有限 | 提示需个体化评估是否继续监测 |
| 内镜估计大小与病理测量冲突 | 不自行取值；列出两种取值对应的分档，由选定指南/医院规则决定 |
| 肠道准备不充分、未到达盲肠、切除不完整 | 常规间隔不适用，需先短期复查 |
| 引用 2010 年前的"增生性息肉"研究 | 提示当时的 HP 中有一部分按现行标准属于无蒂锯齿状病变，术语版本不同 |
| 证据只来自动物、体外、机制研究或单个病例 | 说明不能直接用于临床决策 |
| 证据人群与提问人群不同（国家、筛查/有症状、年龄段） | 说明外推的局限 |
| 库内没有对应指南原文（如需要具体指南条款） | 说明结论来自指南草稿【待原文核对】或库内暂无 |

## 检索
命中的情况要用证据说明后果：把命中的情况本身（特殊人群、测量误差、检查质量问题、术语变化等）写成英文检索词，
用 `search_literature` 在全部题录中找相关研究，读摘要后引用。不要只查 40 篇全文段落。

## 原则
- 宁可说"不适用/证据不足/需要补充信息"，也不要给出看似确定但前提不成立的答案。
- 系统不替医生做取值决定，只把冲突和后果摆清楚。
- 说明两种取值对应的分档时，分档和间隔只能引用 surveillance-interval 技能表（标【待原文核对】），不要自己编间隔。
